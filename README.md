# Легион ⚔️

Уютная стратегия про захват мира в виде Telegram Mini App. Командуй армиями,
занимай соседние земли в бою на кубиках и собирай под своим знаменем целые
регионы. Кто останется единственным правителем карты, тот и победил.

Своя карта из 20 земель и 5 регионов, свои правила: без чужих торговых марок.

## Как играть

Ход состоит из трёх фаз:

1. **Подкрепление** — получаешь армии (тем больше, чем больше у тебя земель, плюс
   бонус за полностью занятый регион) и расставляешь их по своим территориям.
2. **Наступление** — атакуешь соседние вражеские земли. Бой на кубиках: у
   нападающего до трёх, у защитника до двух, ничья в пользу защиты.
3. **Манёвр** — один раз перебрасываешь армии между своими соседними землями и
   заканчиваешь ход.

Захватишь последнюю землю соперника, он выбывает. Займёшь всю карту, ты победил.

## Режимы

- **Одиночная игра** против ботов, три уровня сложности (легко / средне / сложно).
- **Быстрая игра** — случайные соперники онлайн (столы добираются соперниками
  автоматически).
- **Игра с друзьями** — общая комната по коду из четырёх символов.

## Архитектура

Монорепо на npm workspaces:

- `shared/` — изоморфная логика: карта (`map.ts`), движок (`engine.ts`), боты
  (`bots.ts`), детерминированный RNG (`rng.ts`), проекция вида (`view.ts`), типы.
  Один и тот же код крутится на клиенте (мгновенное соло) и на сервере
  (авторитетный онлайн), поэтому партии воспроизводимы.
- `server/` — Hono + better-sqlite3 + grammy. REST API, авторизация по Telegram
  initData с выдачей JWT, менеджер онлайн-комнат в памяти, вебхук бота, раздача
  собранного SPA.
- `app/` — React + Vite + Zustand. Экраны меню, лобби и карты, SVG-отрисовка
  гексовой карты, синтезированные звуки через WebAudio, интеграция с Telegram
  WebApp.

## Разработка

```bash
npm install
npm run dev:server   # сервер на :3000 (DEV-режим без BOT_TOKEN)
npm run dev:app      # Vite на :5174 с проксированием /api

npm test             # тесты движка и карты
npm run typecheck    # проверка типов сервера и клиента
npm run build        # сборка SPA в app/dist
```

Без `BOT_TOKEN` сервер стартует в DEV-режиме и подменяет авторизацию одним
локальным пользователем, так что можно играть локально без Telegram.
